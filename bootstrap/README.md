Project: tp1/bootstrap

Files you should have locally (offline-ready):

- index.html  — main demo page (includes navbar, hero, carousel, card grid, footer)
- css/bootstrap.min.css  — Bootstrap 5 CSS (local copy)
- js/bootstrap.bundle.min.js  — Bootstrap 5 JS bundle (includes Popper)
- images/placeholder1.svg  — placeholder for slide 1 (1200×600)
- images/placeholder2.svg  — placeholder for slide 2 (1200×600)
- images/placeholder3.svg  — placeholder for slide 3 (1200×600)
- images/placeholder4.svg  — placeholder for slide 4 (1200×600)

How to test locally:
1. Open `index.html` in your browser (File → Open). The page is static and requires no server.
2. Replace `images/placeholderX.svg` with real photos (suggested size 1200×600, JPEG, optimized) by copying files into the `images/` folder and keeping the same filenames.

Tips to replace images with royalty-free photos:
- Search with keywords: "bouquet close-up red roses", "mixed spring bouquet pastel", "white lilies bouquet elegant", "wildflower gift box bouquet" on sites like Unsplash, Pexels or Pixabay.
- Resize/optimize images with a simple image editor or use command-line tools (ImageMagick or Sharp) to resize to 1200×600 and compress for web.
